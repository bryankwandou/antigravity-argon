# Antigravity Argon — Enterprise IT & Kinetic Web Atelier

Interactive enterprise IT partnership showcase built with React 19, TypeScript, Tailwind CSS v4, GSAP ScrollTrigger, and Lenis smooth scrolling.

## Architecture Highlights

- **Kinetic Choreography**: Preloader counter sequence, GSAP ScrollTrigger scrub progress bar, Lenis smooth wheel inertia, magnetic interactive buttons, line-mask editorial reveals, and dual blend-difference cursor.
- **Centralized Design Tokens**: Complete light and dark mode token system defined in `src/styles/tokens.css`.
- **Bilingual Localization**: Full Bahasa Indonesia (`id`) and English (`en`) runtime switching via `src/locales/id.json` and `src/locales/en.json`.
- **Interactive Telemetry Lab**: Real-time interactive module simulator with adjustable concurrency load and live architecture metrics.
